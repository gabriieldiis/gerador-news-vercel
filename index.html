    Etapa 3 de 6

    Briefing, linha por linha

    Cole o briefing do jeito que chegou. O gerador separa as linhas, reconhece cada uma e pergunta quando ficar em dúvida.

    Ao colar, as linhas entram na lista abaixo. Digitando, use Adicionar.

      As fotos dos produtos não aparecem nesta versão (o link aberto dentro do Claude bloqueia imagens de outros sites). Pelo Iniciar gerador.bat elas aparecem.

      O que o gerador entende
      • 441188 — produto. Busca o link da página do produto, o nome (H1) e a foto.
      • Título - https://… — banner com esse link. Busca, hotsite, categoria e marca são reconhecidos pelo endereço.
      • https://… sozinho — o título vem do H1 da página.
      • Título - 303589-599786-… ou só 798586-798584 — lista de produtos, vira uma busca com todos os códigos. Sem título, o gerador pede um.
      • Título numa linha e link na de baixo viram um banner só.
      • Linha sem link (como JBL sozinho) — o gerador pergunta se é busca, hotsite ou categoria.
      • Linha em branco ou --- separa blocos. Sem blocos, a montagem usa o padrão 1 · 2 · 2.

      Etapa 5 de 6

      Confira a news

      A prévia usa as imagens do servidor quando elas já existem. Você também pode arrastar os arquivos exportados pelo designer.

      Arraste as imagens exportadas aqui ou clique para escolher.
      Cada arquivo entra no banner pelo número do nome (mkt_…_03.png vai para o banner 03).

      Nesta versão (o link aberto dentro do Claude) o navegador bloqueia as imagens do site da Kalunga, por isso a prévia mostra espaços reservados. Para ver as imagens reais, abra o gerador pelo Iniciar gerador.bat ou pelo endereço publicado. Aqui você ainda pode arrastar os arquivos exportados pelo designer.

      Clique num banner da prévia para editar título, link e posição. Ctrl + clique abre o link.
